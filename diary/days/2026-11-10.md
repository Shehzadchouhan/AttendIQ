## Tasks Done

I implemented the group classroom attendance workflow in `backend/app/api/v1/attendance.py`, enabling teachers to upload a classroom group photograph or capture one live using `WebcamModal.jsx`. I built the facial recognition matching logic using a greedy bipartite matching algorithm that pairs detected bounding boxes to enrolled student vectors with tri-state confidence labeling (Green >= 0.45, Amber 0.35–0.45, Red < 0.35). I generated and applied Alembic migration `0004_session_batch_date_unique` to enforce a unique constraint on `(batch_id, session_date)`. For analytics, I developed the reports router (`backend/app/api/v1/reports.py`) and frontend reports page (`Reports.jsx`) with Recharts visual graphs, 28-day attendance heatmaps, at-risk student lists (<75% attendance), and streaming CSV exports. I added brute-force login protection using SlowAPI rate limiting (5 req/min). Finally, I configured GitHub Actions CI workflows for linting, pytest with coverage, production Docker builds, and deployment instructions (`DEPLOYMENT.md`).

## Problems Faced & Design Decisions

<!-- REVIEW: Sheh to confirm he can explain this -->

1. **Preventing Duplicate Face Matches in Group Photographs**: When matching multiple detected faces against enrolled student embeddings, a naive nearest-neighbor search could assign two different detected bounding boxes to the same enrolled student. I implemented a greedy bipartite matching algorithm in `backend/app/api/v1/attendance.py` that computes all pairwise cosine similarities, sorts them in descending order, and iteratively assigns matches while marking both the matched student and the bounding box as claimed.
2. **Preventing Duplicate Session Records**: Submitting attendance twice on the same day for a single batch could generate duplicate records and distort statistics. I generated and applied Alembic migration `0004_session_batch_date_unique.py` to enforce a composite unique constraint on `(batch_id, session_date)` in PostgreSQL, returning an HTTP 409 Conflict if a session already exists for that date.
